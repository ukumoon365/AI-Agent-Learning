# AI chat Practice 
```text
1. 프로젝트 소개

LangChain과 Streamlit을 활용하여 개발한 연습용 AI 채팅 애플리케이션입니다.

여러 LLM 모델을 선택하여 대화할 수 있으며, 대화 기록과 토큰 사용량 및 API 사용 비용을 확인할 수 있습니다.

배포 주소

Demo: https://kyeong-ai-agent-practice.streamlit.app/ 

GitHub: https://github.com/ukumoon365/AI-Agent-Learning/tree/main/%EA%B0%9C%EB%B0%9C%20%EC%9E%85%EB%AC%B8/AI%20chat%20application

2. 주요 기능
- 여러 LLM 모델 선택 기능
- Temperature 조절 기능
- 사용자와 AI 간 대화 기능
- 대화 기록 유지 기능
- 대화 내역 삭제 기능
- 토큰 사용량 확인
- API 사용 비용 계산 및 표시

3. 주의사항
API 비용 문제로 인해 LLM 모델은 Google의 gemini만 사용 가능합니다.
(코드 구현은 GPT,Claude,Gemini로 되어있습니다)
```
